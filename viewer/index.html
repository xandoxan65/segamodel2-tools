Sega Rally Assets

Track data comes from the placement stream (draw script @ 0x28656C0), not ROM bank dumps. Start with the four course entries (Desert / Forest / Mountain / Championship) — one export per menu track.

Course tracks include face data (wireframe/solid) and palette-tinted UV textures — pick Textured for Desert / Forest / Mountain / Championship (55 palette variants on desert).

Body shells 96–99 and 106–107 share one identical mesh in ROM.

python3 -m tools.extract.asset_index && python3 -m tools.extract.manifest
